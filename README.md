Leonida Legend is an offline GTA 6 trophy guide and tracker covering all 55 PS5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden) with the official names and descriptions, an own-words guide and named sources for every trophy, a five-stage roadmap to the platinum, honest missable flags, and a spoiler shield that masks un-earned story trophies. Progress is a checklist saved in your browser's localStorage, with export and import, search, and filters by kind and grade. The app makes no network requests and loads only its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Hand in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
