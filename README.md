Leonida Legend is an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. It covers the game's full list of 55 trophies — 1 platinum, 2 gold, 6 silver, 46 bronze, and 28 hidden — using each trophy's official name and description. Every trophy comes with a guide written in our own words, together with the named sources that guide draws on, so you can always see where a tip comes from. A five-stage roadmap sets out a sensible order for the road to the platinum, trophies that can be missed are flagged before you pass the point of no return, and a spoiler shield keeps the names and details of story trophies you have not earned yet hidden until you unlock them. Your checklist progress is stored locally in your browser's localStorage and can be exported to a file and imported back, and the trophy list can be searched and filtered by kind and by grade. The app is fully self-contained: it makes no network requests and works entirely offline.

## What's inside

- All 55 PS5 trophies with their official names and descriptions
- An own-words guide for every trophy, with its sources named
- A five-stage roadmap to the platinum trophy
- Missable trophies flagged in advance
- A spoiler shield that hides un-earned story trophies
- A checklist with search, kind/grade filters, and localStorage progress you can export and import

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To hand in the entry, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
